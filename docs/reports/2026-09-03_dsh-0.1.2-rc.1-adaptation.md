# DSH SDK 0.1.2-rc.1 适配报告

## 背景

上游 `@deepseek-ai/dsh-*` SDK 系列于 2026-09-03 06:07 UTC 发布 `0.1.2-rc.1`。本插件此前锁定 `0.1.2-alpha.4`（peer 与 dev 双份精确版本），需要跟进适配。

## 调研结论

对项目依赖的全部 16 个 dsh 包逐一拉取 npm tarball（alpha.4 / alpha.5 / rc.1）做文件级对比：

- **代码零变更**：所有包在 alpha.4 → alpha.5 → rc.1 之间 `lib/` 产物与类型声明完全一致，仅 `package.json` 版本号变化。本次 rc.1 是纯版本发布，无 API 破坏性变更，无需改源码。
- **rc.1 为部分发布**：`dsh-client-ui-chat` 与 `dsh-client-ui-slots` 未发布 rc.1（npm 上最新为 `0.1.2-alpha.5`），其余 14 个包均有 rc.1。两者内容与 rc.1 同代（alpha.5 与 rc.1 仅版本号差异），且其 peerDependencies 只要求 `@deepseek-ai/cordis ^4.0.2`，不约束兄弟包版本，混用安全。
- `dsh-api-session-controller` 等 rc.1 包自身的 runtime 依赖为 `^0.1.2-rc.1` caret 区间，不涉及上述两个 UI 包，无解析冲突。

## 变更清单

| 文件 | 变更 |
| --- | --- |
| `package.json` | 14 个 dsh 包（peer + dev 共 28 处）`0.1.2-alpha.4` → `0.1.2-rc.1`；`dsh-client-ui-chat`、`dsh-client-ui-slots`（共 4 处）→ `0.1.2-alpha.5` |
| `scripts/check-repository-rules.mjs` | 版本断言拆为两组：13 个包断言 `0.1.2-rc.1`（"must match DSH Desktop rc.1"）；ui-chat / ui-slots 断言 `0.1.2-alpha.5` 并注明未发布 rc.1 |
| `README.md` / `README.zh.md` | 两处兼容性说明 `DSH 0.1.2-alpha.4` → `DSH 0.1.2-rc.1`（L25 profile 要求、L117 源码版本面向） |
| `.i18n/README.i18n.yaml` | 同步 README 变更后的 git blob 哈希 |
| `pnpm-lock.yaml` | 随 `pnpm install` 更新 |
